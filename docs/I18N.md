# 国际化（i18n）

**UI 壳三语**（简体 / 繁體 / English），**正文不翻译**；语言存 `localStorage` + cookie（`penn-ui-locale`），不改文章 URL。

## 怎么切换

顶栏「语言 · 外观」面板：切语言会刷新；切外观即时生效。

## 覆盖范围

| 区域 | 方式 |
|------|------|
| 顶栏 nav / 页脚 / 搜索 / 404 | `theme-config` + `applyThemeChrome` |
| 归档 / 标签 / 专题 / 系列 / 新闻 / 友链 / 近况 / 评论等 | Vue `useI18n()` |
| 首页 / 栏目页壳层 | 构建产物 `data-i18n` + `applyDomI18n` |
| 音乐胶囊 / 助手主壳 / 代码折叠 | `getUiText` / `useI18n` |

正文 Markdown、助手建议提问 chips、书单条目说明等仍可为中文。

## 如何加文案

1. 壳层通用：`website/.vitepress/i18n/messages.ts`
2. 页面级：`website/.vitepress/i18n/page-messages.ts`（并在 `types` 的 `PageMessages` 补类型）
3. Vue：`useI18n().t('…')`；DOM 脚本：`getUiText()`
4. 构建 HTML：加 `data-i18n="home.xxx"`，可选 `data-i18n-args="12"` / `data-i18n-aria="…"`

## 相关文件

- `theme/ui-locale.ts` — 偏好存储
- `theme/dom-i18n.ts` — 刷 `data-i18n`
- `theme/LocaleSwitcher.vue` — 语言+外观面板
- `i18n/theme-config.ts` — nav / footer / 搜索壳文案
